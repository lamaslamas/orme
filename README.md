# Orme

Web app personale (PWA) per raccogliere e percorrere i sentieri faunistici del
Parco Nazionale d'Abruzzo, Lazio e Molise (orso, lupo, camoscio, cervo).

Aperta su: https://lamaslamas.github.io/orme/

I dati restano solo sul dispositivo (IndexedDB). Usa la pagina **Backup** per
esportarli o importarli in JSON.

## Sviluppo

```bash
npm install
npm run dev     # avvia l'app in locale
npm test        # esegue i test
npm run build   # crea la versione da pubblicare in dist/
```
